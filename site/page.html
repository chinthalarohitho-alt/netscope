How it works

It listens where the calls already are.

Most debug builds already log their traffic through OkHttp, and Chrome exposes its own over adb. Netscope reads both, so there's nothing to install on the phone and no certificate to trust.

Features

Built for the moment after you find the call.

Find

Filter the way DevTools does.

Funnels on every column header, and a search box that understands the same syntax as Chrome's Network panel. Type a key and it suggests the values it has actually seen.

mime:application/jsonstatus:>=400-domain:*.cdn.examplelarger-than:100kis:slowmethod:POST
Replay

A full API client, next to the traffic.

Open any captured call in the client, change it and send it again. Keep requests in collections and folders, switch environments, and test responses with the same pm scripts you'd write in Postman.

  • Collections, folders and {{variables}} per environment
  • Pre-request and post-response scripts with pm.test
  • Markdown docs on every request
  • Postman v2.1 and cURL import and export
Compare

See what changed between two responses.

Pin a call, pick another, and read a line diff of their bodies or headers. The quickest way to see why the same endpoint failed once and worked the next time.

Connect

Pair a phone over Wi-Fi in one scan.

Show a QR code, scan it from the phone's Wireless debugging screen, and Netscope pairs and connects. Phones you've paired before show up under Nearby with a Connect button.

Optional

Add one line when you want everything.

Logcat cuts long bodies and release builds don't log them at all. The Netscope interceptor streams each call to your Mac over adb instead: complete bodies, exact timing, and nothing sent anywhere else. If the app also logs through OkHttp, each call still shows once.

Anyone with adb access to the device can read what the library captures, so ship it only in builds you're happy to inspect.

Install

Download, connect a phone, done.

1

Download Netscope and drag it into Applications.

Download for MacApple Silicon · free · .dmg

Or install it with Homebrew, which also keeps it up to date:

$brew install --cask chinthalarohitho-alt/tap/netscope
2

Install adb if you don't have it.

$brew install --cask android-platform-tools
3

Connect a phone with USB debugging on, start an emulator, or pair over Wi-Fi from inside Netscope. Calls appear as soon as the app makes them.

The first time you open the downloaded app, macOS may say it can't check it for malicious software. Open System Settings → Privacy & Security and click Open Anyway. The Homebrew install doesn't need this step.
